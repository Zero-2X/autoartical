# 博士论文式版式技能

当文档需要正式、可打印、接近博士学位论文的结构时使用。先读取 [博士论文式申报书版式契约](../../workflow/references/doctoral-thesis-format.md)，再执行导出脚本；不要把“博士论文式”理解为虚构学校、学位或导师信息。

## 生成规则

- 采用封面、材料真实性说明、中文摘要、英文摘要、目录、正文、参考文献、附录和致谢/说明的顺序；申报书没有某一部分时标记“待填写”或明确省略原因。
- 正文使用章—节—小节层级，导出副本给所有 H2–H6 加显式编号：前置部分为 `0.x`，正文为 `第N章`、`N.N`、`N.N.N`；图表编号统一为 `图 1-1`、`表 1-1`，标题、图表和引用保持全书一致。
- 采用 A4、上/下/左/右约 30/25/26/26 mm，12 pt 中文正文、英文数字 Times New Roman、两端对齐、首行 2em；字体不可用时记录回退字体。
- 交付副本自动合并同一标题范围内的短正文段；图表说明、列表、引用、公式、标题和图片是硬边界，不能把不同论证合并成一段。
- 页眉、页码、目录和分页必须在真实 PDF 上核验。封面不放页码；正文页脚显示当前页/总页数。
- 必须生成可编辑 `.docx`，使用宋体正文、黑体标题、Times New Roman 英文数字、固定值 20 pt 行距、首行 2 字符缩进和 A4 版心；Word 需要经过 `render_docx.py` 全页栅格化和视觉 QA。
- 赛事要求覆盖本契约时，保留研究内容和证据门禁，只替换版式参数，并将覆盖关系写入导出 manifest。

## 运行与验收

1. 检查 Markdown 标题、图表标记、引用台账和项目元数据。
2. 运行 `python workflow/scripts/run_document_export.py <topic-dir>`，生成 Markdown、HTML、DOCX 和 PDF。
3. 用 documents skill 的 `render_docx.py`（Windows 若未安装 LibreOffice，则用已安装 Word 的固定版式 PDF 导出作为等价实际渲染）将 DOCX 栅格化为全部页面，人工抽检首页、中段、图表密集页和末页，然后运行 `record_docx_qa.py`；同步用 `pdftoppm` 和 `record_render_qa.py` 验收 PDF。Word 允许因排版引擎重排页数，但必须保留同源全文、至少 40 页并通过逐页 QA；PDF 严格执行 40–50 页。
4. 若门禁失败，回到标题结构、段落合并或内容分页修复；不得缩小字体、增设空白页或用封面/目录代替正文。
