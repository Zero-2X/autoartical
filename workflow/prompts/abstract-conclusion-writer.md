# writing Prompt - Abstract / Conclusion Writer

你的任务是基于我提供的、已基本完成的论文全文草稿 (Full Draft)，严格遵循我独特的叙事风格和逻辑模板，分别撰写 `\begin{abstract}...\end{abstract}` 和 `\section{Conclusion}` 部分的完整、可编译的 LaTeX 代码，直接写入原文 tex 中对应位置。这两部分请尽量不要插入符号和公式，这两部分都是只写一段。

## 摘要 (Abstract) 写作协议

摘要是论文的“电梯演讲”，必须在有限的篇幅内清晰地传达工作的全貌。你的撰写必须遵循以下“问题-方案-贡献”的叙事模板：

1. 宏观背景 (1 句话)：以一句高度概括的话点明我们所处的宏观研究领域及其重要性。
2. 抛出问题 (1-2 句话)：紧接着，精准地识别并抛出现有工作中的一个关键缺陷或根本性挑战。这部分要有冲突感，为我们方法的出场制造必要性。
3. 引出我们的框架 (1 句话)：直接、自信地提出我们的解决方案，并将其定位为应对上述挑战的直接解决方案。
4. 核心方法/组件 (2-3 句话)：简要介绍框架中的 1-2 个核心技术组件或方法，并阐明它们各自的作用，这部分要 high-level 体现技术的作用。
5. 实验与定量结果 (1 句话，举例子)：用一句话总结实验验证的有效性，并且必须包含至少一个具体、亮眼的定量结果来增强说服力。

## 结论 (Conclusion) 写作协议

结论是对全文工作的回顾与升华，语气要更加自信和总结性，侧重于重申我们方法的贡献和价值。Conclusion 只写一段。

1. 工作重述 (1-2 句话)：开篇直接、概括性地重述本文的核心工作。
2. 方法回顾 (2-3 句话，侧重于方法)：再次回顾我们提出的核心方法或技术组件。与摘要不同，这里可以稍微展开，强调“我们的贡献”。
3. 成果总结 (1-2 句话)：总结性地陈述我们方法所取得的优越成果，可以再次引用关键的实验数据来支撑。
