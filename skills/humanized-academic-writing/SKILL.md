# 专业化学术写作技能

适用于论文、申报书、研究报告和技术白皮书的长文写作与复审。先读取 [专业化与作者化写作契约](../../workflow/references/humanized-academic-writing.md)，必要时参考个人 `humanizer-zh-academic` 和 `thesis-optimizer` skill。目标是提高信息密度、证据对应关系和作者在场感，而不是把全文改成统一口语。

## 必须保护的内容

数字、单位、引用、公式、变量、数据集、图表编号、否定、条件、时间、归因、实验状态和结果等级不得被改写器擅自改变。没有来源的事实不通过改写补出来；计划、案例和外推不能写成已完成结果。

## 复审循环

1. 扫描段首理论套话、段末总结套句、空泛意义、模糊权威、整齐三元并列、重复段首、堆叠限定词、无主语被动句和标题复读。
2. 先删没有信息的引导语，再做句内重排；让最重要的理由多说，次要理由简写，不强行凑成三项。
3. 对每个高风险段落保留原文、修改后文本、命中模式、受保护字段和修改理由。
4. 回归检查引用与数字、句子节奏、章节长度、段落重复、证据等级和语域；发现结论变强、语气变口语或限制条件丢失时回滚。

## 自动门禁

工作流的 style gate 可以给出可解释风险报告，但不得输出“AI 率”并把它当作商用检测器结论。高风险模式只触发局部修订建议；普通排比、破折号和连接词按密度及语义保留。无出处的“专家认为/研究表明”和无边界的“具有重要意义/前景广阔”进入定稿即失败。
