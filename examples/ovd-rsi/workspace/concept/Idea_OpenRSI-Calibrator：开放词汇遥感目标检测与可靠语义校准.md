# OpenRSI-Calibrator：开放词汇遥感目标检测与可靠语义校准

## 项目背景

competition-rules强调作品的创意、技术方案及其实现质量、应用价值和讲解表现。遥感开放词汇检测真正要解决的不是把更多类别名称放进模型，而是让用户能够用新词汇查询目标，同时知道结果是否定位正确、是否存在类别幻觉以及哪些结果需要人工复核。从现有研究与样例脉络看，Object Detection in Optical Remote Sensing Images 表明 遥感检测需要在跨场景、类内差异和小目标条件下评估，不能直接照搬自然图像类别假设；DOTA 表明 用任意方向四边形标注航空影像目标，覆盖尺度、方向和形状变化，这说明该方向对应的是持续存在、且适合做成系统闭环的真实问题。

## 核心方案

方案定位上，构建以文本查询为入口的遥感开放词汇检测系统，先用遥感域视觉语言原型对齐查询，再用多尺度和旋转候选完成定位，最后用类别—区域一致性、背景抑制和温度校准输出带证据的可靠结果。系统不再把采集、判断和处置建议拆成彼此孤立的模块，而是按“数据接入 - 状态分析 - 结果评估 - 联动执行”的链路组织。结合 Object Detection in Optical Remote Sensing Images 表明 遥感检测需要在跨场景、类内差异和小目标条件下评估，不能直接照搬自然图像类别假设；DOTA 表明 用任意方向四边形标注航空影像目标，覆盖尺度、方向和形状变化；FAIR1M 表明 细粒度近义类别会放大提示词和语义原型混淆，必须报告类别层级和错误类型，当前更合理的做法不是只做一个分类器，而是搭建可解释、可联动、可扩展的分层流程。

## 关键创新

### 创新一 · 遥感域词汇原型适配

利用遥感图文表示校正通用文本嵌入，使同一类别在俯视尺度、方向和纹理条件下保持稳定语义。 在整体架构中，这一模块承担 系统链路中的关键模块，Object Detection in Optical Remote Sensing Images 表明 遥感检测需要在跨场景、类内差异和小目标条件下评估，不能直接照搬自然图像类别假设；DOTA 表明 用任意方向四边形标注航空影像目标，覆盖尺度、方向和形状变化；因此它不是孤立功能点，而是后续系统闭环得以成立的关键支点。

### 创新二 · 多尺度旋转候选协同

利用类别—区域一致性、背景对照和温度校准抑制类别幻觉，输出可解释的不确定性和人工复核建议。 在整体架构中，这一模块承担 系统链路中的关键模块，Object Detection in Optical Remote Sensing Images 表明 遥感检测需要在跨场景、类内差异和小目标条件下评估，不能直接照搬自然图像类别假设；DOTA 表明 用任意方向四边形标注航空影像目标，覆盖尺度、方向和形状变化；因此它不是孤立功能点，而是后续系统闭环得以成立的关键支点。
