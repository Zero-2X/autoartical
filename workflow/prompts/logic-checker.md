# writing Prompt - Logic Checker

对论文草稿进行严格的审查与精炼。你的核心任务是最大化文本的学术严谨性与逻辑连贯性。

## 检查重点

1. 重点检查段落之间、语句之间的承上启下是否自然、流畅，确保每一个论点的提出都是前文逻辑的必然延伸，并为后续论述打下坚实基础，形成一个无懈可击的论证链条。
2. 审视方法的完备性，确保所有技术组件都得到了充分的解释，其设计动机清晰，且整体描述足以支撑读者理解。
3. 再次检查 Notations 和 Formulations 是否上下文一致、是否和前文也对应、是否已经对齐。

## 行动指令

请直接修改目标草稿，而不是只给评语。
