# 视航守望：面向桥区复杂水域的船舶视觉感知与风险证据闭环系统

> 申报书第一版底稿｜科技创新/人工智能应用类比赛通用版｜版本：draft-1
>
> 本稿已经完成选题研究链条和实验协议的第一轮组织。由于赛事章程、真实桥区数据和完整论文核验尚未提供，以下结果性表述均保持为研究计划，不把预期指标写成已完成成果。

## 一、项目摘要

桥区水域同时具有桥墩遮挡、航道收窄、船舶交会、逆光雨雾和目标尺度变化等特点。现有视频监控常能在单帧中“看见船”，却难以持续回答三件事：画面中断后是否仍是同一艘船，目标是否正在接近风险区，以及告警能否被监管人员复核。项目拟构建“视航守望”船舶视觉感知与风险证据闭环系统，以视频流为入口，联合场景质量评估、船舶检测、多目标跟踪、遮挡轨迹重连、航道空间先验和不确定性校准，输出带轨迹、原始片段、接近时间和置信度的分级风险事件。

项目的核心研究问题是：在桥区遮挡和低能见度条件下，场景质量与不确定性建模、基于空间先验的轨迹重连、证据卡组织能否在相近延迟下减少 ID 切换与误报，并提高风险事件的可复核性。项目不把视觉模型输出直接等同于法律责任判断，而是把它定位为海事监管的辅助感知和事件回放工具。预期形成一套可部署原型、一个分层标注的桥区船舶视频数据集、一套可复现实验协议和一组失败案例库。

## 二、选题依据与研究价值

### 2.1 研究领域

项目属于智能航运与计算机视觉交叉领域，具体落在复杂水域环境感知。近期复杂水道视觉感知综述将动态水面扰动、复杂光照、恶劣天气和小目标列为影响自主水面航行器感知的主要因素[1]。海事视觉基准也表明，开放水域目标检测、跟踪和分割需要专门的数据与评价协议，不能直接照搬陆地图像的结论[2][3]。

选择这一领域有三个原因。第一，桥区事故后果具有明显的空间集中性，桥墩、航道边界和限行区为风险判断提供了比普通开放水域更清晰的几何约束。第二，视频设备已经广泛存在，若能把离线视频转化为连续轨迹和可审计事件，就能以相对低的新增硬件成本扩大监管覆盖。第三，视觉感知的错误会沿着“检测—跟踪—风险判断”链条累积，必须研究完整闭环，而不是只展示一个检测框。

### 2.2 子领域与研究边界

项目研究的子领域是复杂水域船舶检测、多目标跟踪与通航风险证据生成。检测解决“画面里有什么”，跟踪解决“是否是同一目标”，风险证据解决“为什么系统触发了事件”。三者的连接是本项目的研究对象。项目不研究船舶自动驾驶控制，不替代海事人员的最终判断，也不声称仅凭视频即可判定法律责任。

### 2.3 通用挑战及其影响

水面反光、雨雾和逆光会改变船舶外观，使检测置信度不稳定；桥墩遮挡和密集交会会造成观测中断，导致 ID 切换和轨迹碎片；公开数据与真实桥区存在域差异，离线指标可能无法代表现场效果；如果告警只有一个分数而没有轨迹和原始片段，监管人员无法快速复核。这些挑战分别对应漏检/误检、IDF1 下降、迁移性能下降和处置证据不足，项目将逐一转化为实验子集和指标。

### 2.4 用户需求与科学问题

项目面向海事监管部门、桥区航道管理单位和港口水运企业。监管人员的直接需求是：在多个视频画面中快速发现需要复核的事件，看到目标从哪里来、何时进入风险区、系统依据是什么，并能把事件片段交给后续处置流程。对应的**科学问题**是：如何在观测缺失和视觉退化条件下，把目标身份连续性、不确定性和空间风险证据统一到一个可测、可复现的视觉感知模型中。

| 用户需求 | 系统输出 | 验证方式 |
|---|---|---|
| 发现持续接近风险区的船舶 | 连续轨迹、驶入时间、方向 | HOTA、IDF1、提前量 |
| 区分可信告警与看不清 | 质量标签、校准置信度、人工复核标记 | ECE、误报率、复核协议 |
| 快速回放并说明告警原因 | 证据卡、前后片段、触发规则 | 证据完整率、复核步骤数 |

## 三、国内外现有方法与关键缺口

### 3.1 方法分类

第一类是单帧目标检测，以 YOLO 或 RT-DETR 等模型逐帧预测船舶框和类别。它结构简单、容易实时运行，适合计数和粗粒度监测；缺点是不维护身份，对遮挡和低能见度敏感，不能直接支持连续风险判断。

第二类是检测加多目标跟踪，以检测框、运动模型和外观特征关联跨帧身份，ByteTrack、OC-SORT 等方法可作为强基线。它能输出轨迹，评价协议较成熟；但遮挡后容易发生 ID 切换，且域偏移会同时损伤检测和关联。

第三类是图像增强或域适配后检测，先进行去雾、去雨、光照补偿或域对齐，再接入检测器。它能针对视觉退化补偿，但增强可能引入伪影，也不能自动解决身份连续和置信度校准问题。

第四类是轨迹规则与风险告警，利用虚拟航道线、距离、接近时间和速度关系触发事件。它可解释、便于接入监管流程，但高度依赖上游轨迹质量，固定阈值跨场景不稳定。四类方法在公开海事视觉挑战和复杂环境研究中各有适用边界[1][3][4]。

### 3.2 关键缺口

现有系统常把检测、跟踪和规则告警串联，却没有同时表达三种信息：观测是否可靠，遮挡期间的身份假设是否可信，告警证据是否完整。于是模型可能在看不清时输出过度确定的结果，轨迹短时断裂后发生误配，监管人员只能看到告警数字而无法看到产生告警的证据链。项目据此提出一个可证伪问题：联合场景质量与不确定性、空间先验轨迹重连和证据卡，能否在相近延迟下改善遮挡/低能见度子集，并降低风险告警误报。

## 四、总体目标与技术路线

### 4.1 总体目标

构建面向桥区复杂水域的低成本视觉感知原型，形成“视频接入—场景质量评估—船舶检测—多目标跟踪—遮挡重连—风险推理—证据回放”的闭环。项目以三个结果作为验收对象：连续身份轨迹、分级风险事件、可复核证据卡。

### 4.2 技术路线

1. **场景质量评估与不确定性表达**：从亮度、雾度、反光和目标尺度等可观测线索估计当前视觉条件，输出质量标签和校准后的检测置信度；当证据不足时保留“不可判定”状态。
2. **检测与跟踪协同**：使用统一检测器与强跟踪基线建立对照，在桥墩、航道边界和虚拟线约束下维护候选轨迹。
3. **遮挡轨迹重连**：结合短时运动预测、航道空间先验和外观相似度建立重连候选，使用门控机制限制跨区域误配，并记录重连依据。
4. **风险证据卡**：将目标轨迹、虚拟航道线、驶入时间、速度/方向、置信度和前后若干秒原始片段绑定，输出分级事件。证据卡记录模型版本、时间戳和触发规则，支持复核和回放。
5. **闭环评估**：按天气、遮挡、交会、尺度和设备位置分层评估，报告平均指标、置信区间、失败案例和资源消耗。

## 五、创新点与科学 rationale

**创新点一：把“看不清”从错误预测中分离出来。** 复杂水面场景中低置信度不一定意味着没有目标。场景质量与不确定性头的作用是让系统能明确表达观测不足。可检验预测是：雨雾/逆光子集的校准误差和误报率下降。

**创新点二：把桥区几何约束用于轨迹重连。** 桥墩和航道边界提供稳定空间先验，可压缩遮挡后候选匹配空间。可检验预测是：遮挡子集的 IDF1 提高，ID 切换和轨迹碎片减少；同时必须报告误配是否增加。

**创新点三：把告警从分数变成证据卡。** 风险事件不只保存一个概率，还保存轨迹、触发规则和可回放片段。可检验预测是：在固定召回目标下误报率下降，证据完整率提高，人工复核所需步骤减少。人工复核效率必须通过预先定义的任务和计时协议验证，不能用主观描述代替。

## 六、案例研究

案例选择“桥墩遮挡后的交会与驶入限制区”：两艘船在桥墩前后交会，其中一艘短时消失并重新出现。系统需要保持身份连续，估计其驶入虚拟限制区的时间，并生成包含遮挡前后片段、轨迹重连依据和置信度变化的证据卡。

案例研究不用于代替主实验，而用于检查机制是否按预期工作。需要记录遮挡持续时间、船舶间距、再出现位置、候选轨迹数量、重连是否成功以及风险规则是否被误触发。失败样本必须保留，用于说明系统边界。

## 七、主实验设计

### 7.1 数据与 benchmark

公开部分拟使用 MaCVi 海事视觉任务作为检测、跟踪和分割任务设计参考，并使用 SeaDronesSee 作为海事视觉鲁棒性参考；SeaDronesSee 的目标类别与本项目船舶类别不同，因此只在类别边界清晰、协议可比的任务上使用，不能把其结果表述为船舶检测结果[2][3]。核心评估采用自建桥区船舶视频集，按晴天、逆光、雨雾、桥墩遮挡、密集交会、远小目标分层，标注检测框、轨迹 ID、遮挡区间、虚拟航道线和风险事件。

数据切分按时间和摄像机位置隔离，避免同一连续视频泄漏到训练与测试。每个测试序列保留原始帧、标注版本、场景标签和数据哈希。采集时进行人脸、车牌和敏感信息脱敏，并记录设备高度、焦距、帧率和天气条件。

### 7.2 基线、指标与证明目标

基线包括 YOLO/RT-DETR + ByteTrack、YOLO/RT-DETR + OC-SORT、增强或域适配模块加同一跟踪器，以及仅依赖轨迹规则的告警基线。检测指标为 AP50、AP50:95、Precision 和 Recall；跟踪指标为 HOTA、IDF1、ID Switches 和轨迹碎片数；风险指标为事件召回率、误报率、提前量、证据完整率和校准误差 ECE；系统指标为端到端延迟、FPS 和资源占用。

主实验要证明的是：联合方案在关键困难子集上改善身份连续和风险告警质量，而不是只提高一个平均检测分数。消融实验分别移除不确定性头、空间先验、轨迹重连和证据卡，观察每个组件是否产生独立贡献。统计上固定随机种子、序列切分和阈值选择规则，并报告置信区间；若提升只出现在某一摄像机或某一天气条件，结论必须限定在该边界内。

### 7.3 暂定成功判据

- 遮挡子集的 IDF1 相对最强基线提升，且固定重采样协议下 95% 置信区间不跨零；
- 在固定事件召回目标下，风险误报率下降，提前量不低于基线；
- 端到端延迟满足实际演示设备的实时约束，具体阈值由设备实测确定；
- 每个结论都能回链到数据划分、日志、指标脚本和失败案例，不能以人工挑选的演示视频替代统计评估。

## 八、实施计划、可行性与成果

第一阶段完成赛事要求核验、场景定义、数据脱敏和标注规范；第二阶段完成检测/跟踪基线和困难子集划分；第三阶段实现不确定性、轨迹重连和证据卡模块；第四阶段完成主实验、消融、失败案例和现场演示；第五阶段按赛事模板完成申报书、技术附件、演示脚本和答辩材料。

项目的可行性来自三方面：检测和跟踪均有可复用的开源基线，桥区视频可从公开海事数据与经授权的本地视频分层构建，风险规则可先以虚拟航道线和接近时间实现，再逐步接入更复杂的场景约束。项目把“现场效果”拆成检测、身份连续、风险事件和证据回放四类可观测指标，便于在资源有限时先完成最小闭环；若真实数据不足，则保留公开数据、仿真遮挡和小规模现场日志三条验证链，并明确各自不能支持的结论。

预期成果包括：一套可运行的桥区船舶视觉感知原型；一份带版本和许可说明的数据与标注规范；一套可复现实验脚本和指标报告；风险证据卡和事件回放界面；围绕算法、软件著作权或专利的成果材料。成果数量和知识产权安排以团队实际能力和赛事规则为准，不在当前版本虚报。

## 九、风险、伦理与边界

真实桥区数据可能受到天气、设备位置和隐私限制，项目将采用公开数据、脱敏自建数据和小规模原型日志分层验证。模型在夜间、强雨雾和极端遮挡下可能失效，系统应输出不确定或需人工复核状态。风险告警仅用于辅助监管和事件回放，不替代船员、海事人员或法律程序的判断。所有演示素材在公开前需完成脱敏、授权和许可核验。
