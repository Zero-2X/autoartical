# External Evidence

Place web-searched papers, reports, datasets, and manually curated evidence notes here.

- `external-evidence-intake.json`: structured source list for Step2 import.
- `*.md`: optional search notes, reading memos, or evidence curation logs.

Recommended fields per item:
- source_title / source_url / source_type / source_authority
- claim / summary / derived_insight
- inspiration_points / evidence_for
- applicable_steps / applicable_work_types
- reliability / curation_status / usage_hint / limitations
