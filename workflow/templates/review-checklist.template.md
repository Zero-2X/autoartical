# Paper Self-Review Checklist

- [ ] Abstract states problem, method, evidence, and contribution
- [ ] Introduction states the gap and stakes clearly
- [ ] Method is logically consistent and reproducible
- [ ] Results support the main claims
- [ ] Limitations are explicit and honest
- [ ] Figures and charts match the text narrative
- [ ] Citations are verified or clearly marked
- [ ] Venue requirements are satisfied
- [ ] Main-body page count stays within the venue limit
- [ ] Main-body page usage is close to the allowed limit or explicitly justified
