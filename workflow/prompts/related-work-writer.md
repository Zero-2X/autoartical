# writing Prompt - Related Work Writer

# 任务：生成论文相关工作 (Related Work) 部分的 LaTeX 代码

你的任务是根据我指定的研究领域，撰写一段逻辑清晰、引用详实、格式严谨的 `\section{Related Work}` 部分的完整、可编译的 LaTeX 代码，并确保所有引用的参考文献都提供了对应的 BibTeX 条目。

## 核心写作协议 (Core Writing Protocol)

你的写作必须严格遵循一个统一的协议，该协议融合了我独特的写作风格和严谨的文献管理流程。

### 1. 结构与风格 (Structure and Style)

- 章节结构：使用 `\subsection{}` 作为子章节标题来组织相关工作的不同领域。
- 标题风格：每个 `\subsection` 的标题必须是高度概括的单一关键词或短语，精准地定义该子章节的讨论范围。
- 段落叙事流：每个段落都应遵循“总-分-总”的逻辑。以一个主题句开始，概述该领域的核心思想；接着，系统性地梳理该领域的代表性工作，并自然地在字里行间插入大量引用 `\cite{...}`；最后，以一句话总结现有工作的局限性，或点明我们的工作与此方向的区别，从而凸显我们研究的独特性和必要性。

### 2. 文献引用工作流 (Citation Workflow Mandate)

这是一个强制性的两阶段工作流，旨在确保文献的准确性和完整性：

- 第一阶段：文献搜索与 BibTeX 生成 (Search and Generate BibTeX)
  - 在动笔撰写任何文字之前，你必须先根据我给出的主题，上网搜索最相关、最权威的学术论文。
  - 对于你计划引用的每一篇论文，你必须首先生成其完整的 BibTeX 条目。
- 第二阶段：撰写与引用 (Write and Cite)
  - 在完成了 BibTeX 条目的准备工作后，你才能开始撰写 `Related Work` 的 LaTeX 正文。
  - 在撰写过程中，自然地、恰当地使用 `\cite{}` 命令引用你在第一阶段准备好的文献。

## 强制性自我修正流程 (Mandatory Self-Correction Protocol)

在完成 `Related Work` 部分的 LaTeX 代码和所有 BibTeX 条目的初稿后，你必须启动内部自我检查流程，对内容进行最终复核：

1. BibTeX 完整性检查：逐一核对正文中的每一个 `\cite{key}`，确保在下方提供的 BibTeX 代码块中，都存在一个与之完全对应的 `@article{key, ...}` 条目。绝对不允许出现悬空引用。
2. 风格一致性检查：检查子章节标题是否足够凝练，段落逻辑是否清晰，引用是否自然地融入了行文之中。
