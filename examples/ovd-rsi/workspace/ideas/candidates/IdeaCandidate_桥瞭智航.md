# 桥瞭智航

## 开场总述

桥区船舶监管的难点不是简单看见船，而是在遮挡、交会和低能见度条件下持续知道每艘船在哪里、往哪里走、是否正在接近风险区。

## 关键盲区

- 桥墩遮挡会导致检测框短时消失，普通跟踪算法容易产生 ID 切换或轨迹断裂
- 桥区船舶交会密集且尺度变化明显，单帧检测结果难以直接支撑监管判断
- 监控系统如果只输出检测框，无法把轨迹异常转化为可处置的告警事件

## 核心方案定位

构建桥区船舶目标检测与多目标跟踪系统，融合视频检测、轨迹管理、遮挡重连、虚拟航道线和风险规则引擎，形成从监测到告警回放的监管闭环。

## 创新块预览

### 创新一 · 桥墩遮挡轨迹重连

对桥墩遮挡区建立空间先验和短时轨迹预测，降低船舶短时消失后的 ID 切换。

### 创新二 · 检测跟踪协同管理

把检测置信度、运动趋势和外观特征结合起来，提升桥区密集交会场景下的航迹连续性。

### 创新三 · 虚拟航道风险判别

将轨迹与虚拟航道线、桥墩安全区和速度规则关联，输出可回放的风险告警。

## 应用场景与价值

- 面向用户：海事监管部门、桥区航道管理单位、港航监控中心
- 帮助监管人员更早发现偏航、滞留、异常会船和靠近桥墩风险
- 适合用监控大屏、航迹回放和风险列表做答辩展示

## 风险与待确认

- 真实桥区数据可能不足，需要区分公开数据、仿真数据和原型日志
- 视觉模型在雨雾夜间场景下需要说明边界和可扩展方案
